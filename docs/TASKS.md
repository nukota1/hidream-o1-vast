  - Animagine XL 4.0 Zeroをローカル・Vast共通の既定基盤として実装した
  - 基盤profileを `sdxl-animagine-zero` としてLoRAメタデータへ保存し、旧Opt/JANKU用LoRAを非互換として隔離した
